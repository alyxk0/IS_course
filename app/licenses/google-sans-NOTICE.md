# Google Sans

Locally hosted Google Sans, normal style, variable weights 400–700. The Latin and Cyrillic v29 faces match the files loaded by Google Sheets on 2026-10-19 and include the optical-size axis 17–18. Other subsets use v71 at optical size 18.

Source: https://github.com/googlefonts/googlesans

License: SIL Open Font License 1.1, included in google-sans-OFL.txt.

The selected WOFF2 files are unmodified. Sources and SHA-256 digests: src/assets/fonts/sources.json.

Update: node scripts/update-ui-fonts.mjs. The script requires review if the upstream font version changes.
