# Spreadsheet fonts

Unmodified WOFF2 subsets from Google Fonts, locally hosted. Each family uses SIL Open Font License 1.1; individual notices and copyright statements are in sheet-fonts/. No proprietary system font is bundled.

Source: https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33

Sources, selected styles, subsets and SHA-256 digests: src/assets/sheet-fonts/sources.json.

Update: node scripts/update-sheet-fonts.mjs. Review generated font assets and metadata when updating.
